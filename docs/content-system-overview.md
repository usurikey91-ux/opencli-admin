# 项目总览图说明

总览图：[`content-system-overview.svg`](./content-system-overview.svg)

## 图中结论

- 蓝色：仓库中已经存在并接线的能力。
- 橙色：目标流程中还没有接通的能力。
- 绿色：发布后反馈与后续学习。
- 灰色虚线：当前明确不自动启用的动作。

## 概念图提示词记录

Use case: stylized-concept.
Asset type: wide horizontal 16:9 labeled material illustration for a software architecture overview.
Primary request: show a left-to-right pipeline from importing benchmark creator accounts, through OpenCLI Admin public collection, account-relative public popularity detection, selective media acquisition, video-and-copy analysis, derivative content generation, pre-publish checks, and a feedback loop from the user's own published results back to mechanism weighting.
Chinese labels: `对标账号`, `公开采集`, `热度检测`, `素材获取`, `视频拆解`, `二创生成`, `发布检查`, `反馈学习`.
Style/medium: clean Swiss editorial 3D vector-like illustration, off-white background, black ink lines, refined gray surfaces, one vivid IKB blue accent (#002FA7), orange for unfinished modules, green for feedback.
Composition/framing: wide horizontal 16:9, generous safe margins, full pipeline visible, no crop.
Constraints: no logos, no watermarks, no fake UI chrome, no extra English text, no dense legend.

由于当前环境没有可用的图像生成后端，本仓库保留了可复现的 SVG 版本作为项目架构图；它比生成一张不可编辑的图片更适合作为开发期间的单一事实来源。
