# 当前代码状态审计（太阳鸟为主系统）

## 已完成

- 对标账号、作品、公开互动快照和热度检测结果的数据模型。
- 作品发布后 0–48 小时每 4 小时、第 3–7 天每天一次、第 7 天最终快照的策略函数。
- 基于账号最近 20 条历史作品、使用实际可用公开互动指标的相对热度检测。
- `hot` 进入分析队列，`very_hot` 仅提高处理顺序。
- 账号导入、抖音作品分享链接解析作者 `sec_uid`、作品观察页和队列接口。

## 可复用

- OpenCLI 数据源、任务执行器、Cron 调度和浏览器登录态基础设施。
- 内容身份去重、时序快照、公开计数解析、检测证据和分页查询。
- 本轮新增的太阳鸟账号绑定、手动检查和作品拉取契约。

## 需要改造或真实验证

- 选定并验证 OpenCLI 抖音“按账号列作品”的真实命令、参数和返回字段。
- 用一个真实账号确认作品 ID、发布时间、点赞、收藏、评论、分享字段及登录要求。
- 在太阳鸟仓库中接入本轮 API，并将 `hot`/`very_hot` 显示为待分析队列。
- 将素材任务落在太阳鸟：视频、音频、转写、封面、关键帧和评论。
- 真实运行后细化 `account_invalid`、`login_required`、`login_expired` 等错误分类。

## 暂不处理

- OpenCLI Admin 独立运营中台和主 UI 扩展。
- 飞书运行时、通知、自动发布、自动评论、多机部署。
- Cheat on Content 强依赖、账号定位、长期偏好和自动个性化学习。
- 对标作品完播率；该指标只属于自有账号反馈层。
